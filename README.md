# 番茄花园 · Focus Garden

**专注一段时间，收获一朵花。** 在 DeepSeek Harness 的对话里播种、暂停、继续，再把完成的专注时间变成一座 emoji 小花园。

无需 API Key，不发送网络请求，不读取文件。花园按 Harness 会话隔离。

**首版是对话内的计时与文字花园：没有自动弹窗或声音提醒；重启 Harness 或重载插件会清空花园。** 到期后询问花园状态，或调用收获工具确认完成。

```text
🌸 你的番茄花园 · 花开了，可以收获！
目标：完成今天的项目说明
进度 100% · 剩余 0 分 0 秒

🌻 🌷 🌼 🌺 🪷 🌹 💮 🪻

累计收获 8 朵 · 完成 200 分钟专注
```

## 安装

已验证接口版本：**DeepSeek Harness 0.2.2-rc.2**。其他版本尚未验证。

桌面版首次启动会创建 `desktop` profile。先完全退出桌面版，再安装：

```sh
dsh plugin --profile desktop add "https://github.com/qinghuidaqzp/dsh-focus-garden/releases/download/v0.1.0/dsh-focus-garden-0.1.0.tgz"
```

Web 版将 `desktop` 改为 `web`。也可下载 [Release 安装包](https://github.com/qinghuidaqzp/dsh-focus-garden/releases/tag/v0.1.0)，将网址替换为 `.tgz` 文件的绝对路径。

重启 Harness 后即可使用。发行包已经构建，不需要 npm 账号或额外构建权限。

## 怎么玩

直接在对话中说：

- “用番茄花园开始 25 分钟专注，目标是把 README 写完。”
- “暂停花园，我去接杯水。”
- “继续专注。”
- “看看我的花园，现在还剩多久？”
- “时间到了，收获这朵花。”

开始任务会种下一颗种子；随着计时进度出现 🌱 → 🌿 → 🌳 → 🌸。完成后调用收获工具，花园依次解锁 8 种花朵。每株花只可收获一次；未完成或取消的任务不会获得花朵和完成分钟数。

这是**对话内的文字花园与计时工具**：到期状态在下次工具调用时计算，不弹系统通知、不播放声音、不自动唤醒模型，也不会检查你是否真的在专注。若需要提醒，请搭配自己的系统计时器。工具调用立即返回，不会阻塞对话等待 25 分钟。

## 工具

| 工具 | 参数 | 作用 |
| --- | --- | --- |
| `garden_focus` | `action`: start / pause / resume / cancel；开始时填写 `task`，可选 `minutes` | 控制当前专注任务 |
| `garden_status` | 无 | 显示真实剩余时间、进度、花园与累计完成分钟数 |
| `garden_harvest` | 无 | 仅收获已经完成的花朵 |

开始示例：

```json
{"action":"start","task":"写完这次更新说明","minutes":25}
```

暂停不计入成长。只能在一个任务完成并收获后，或取消未完成任务后，再开始新的任务。已经完成的花朵不会被取消操作丢弃。

## 设置与状态

插件设置 `defaultMinutes` 默认是 25，范围 1–180 分钟；每次开始任务也可以指定时长。目标最多 200 字。修改默认设置只影响之后的新任务。

首版状态仅保存在插件进程内存中：**重启 Harness、卸载或重新挂载插件会清空花园和计时**。普通工具调用和同一插件实例内的会话切换不会混用花园。最多保留 128 个会话的花园，达到上限时明确报错，不静默覆盖已有数据。

花园展示最近 48 朵花，累计数量和完成分钟数继续增加。计时使用进程单调时钟，不依赖手动修改的系统日期；应用关闭期间不会继续计时。设备休眠期间时钟行为取决于系统，不能把它当作后台闹钟。

## 源码开发

在 GitHub 源码目录运行：

```sh
npm ci
npm run check
npm pack
```

测试使用可控时钟验证完成时间、暂停恢复、取消、重复收获、会话隔离及容量限制，并使用真实 Cordis / ToolsService 验证原生工具注册、动态配置和取消操作。
